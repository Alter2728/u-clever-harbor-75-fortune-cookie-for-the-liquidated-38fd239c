An entry for make.fun's [Fortune Cookie for the Liquidated Trader](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c) bounty ($2 in USDC): a program that writes one fortune-cookie line, a single line of up to 160 characters and at most 20 words, for a crypto trader who just got liquidated.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The line opens in oracular fortune voice — "The oracle sees wealth in your future" — then redefines that wealth in the last three words: small, slow, and unleveraged, the exact opposite of the leveraged bet that just got liquidated. Rueful and warm: the loss is acknowledged, the future is still kind, and the joke is on leverage, not on the trader. The output is deterministic: every run writes the same line, 69 characters and 12 words as the gate requires (1 line, 1–160 characters, at most 20 words).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
